# 全景相机路线：现状与实施策略

记录日期：2026-09-30。状态依据本项目实际运行与产物，不代表跨软件性能排名。

## 已验证的最短路径

X5 原始双鱼眼 INSV → 同步抽帧 → 鱼眼边界遮罩 → 鱼眼 SfM 与双镜头 rig → 高斯训练 → PLY → 本地网页查看。

Spirula v2026.9.24 使用 OPENCV_FISHEYE 定位；360-camera 预设本次配置 `warp_to_pinhole=true`，训练时每张鱼眼图内部展开为五个透视视图。不能把“原生鱼眼输入”解释为“训练始终直接在鱼眼投影上进行”。

本机 RTX 3090 24GB、约 64GB RAM。耗时仅指相应训练阶段，不含采集、配置、抽帧、SfM、评估、人工检查与排错。完整运行的 661 张训练输入展开为 3,305 个视图；45 张评估输入展开为 225 个视图。74 张未注册，没有进入最终训练。注册视图覆盖各分钟，不等于房间无缺损。

完整评估：PSNR 17.6841、SSIM 0.827277；颜色校正后 PSNR 20.5012、SSIM 0.846446。SfM 使用过全体图像，因此这不是严格隔离的研究基准。图像还存在模糊、漂浮与拉伸；模型不能直接当作精确测量成果。

## 分阶段落地

路线选择的起点是 X5：沿其双鱼眼输入与全景重建线索发现 Spirula 和 AWS 工具箱，优先完成 Spirula，保留 AWS 转换验证。开发目标是让 agent 能参与中间步骤，并把成功与失败的经验用于后续任务。

### 每个阶段都保留 agent 可调整的入口

按“读取日志、配置和产物 → 提出问题与改动理由 → 保存原配置并调整 → 重跑受影响阶段 → 核对结果 → 写回经验”推进。记录工具版本、输入范围、修改前后参数、耗时、检查结论与适用条件。不要把一次有效的参数硬编码为所有素材的默认答案。

已发生的例子是将穷举匹配调整为预筛并复用特征，以及依据实际配置纠正鱼眼训练说明。下一步把这些检查整理为可重复的阶段清单；自动调度尚未实现。“学习”落实为日志、运行手册和 SKILL 的更新，不指模型权重在线训练。

验收：后续任务能读取既有经验，定位当前阶段，说明调整依据并核对结果；失败的尝试也留下适用边界。

### A. 把验证流程做稳定（优先）

将每次任务的输入、程序版本、配置、阶段状态和产物写入独立清单。抽帧、定位、训练、导出、发布查看分别记状态；进程退出且最终文件通过读取检查才算该阶段完成。错误消息应指出失败阶段、日志位置和恢复办法。

验收：新任务能先完成短样片，再按用户授权跑完整素材；失败可重试当前阶段，不重复全部计算；模型缺失时页面明确报错。

### B. 有证据地改善画质

优先检查原图清晰度、遮挡和拍摄覆盖，其次检查未注册图片的时间分布和重投影误差，再做去漂浮、人物遮罩、深度与法线辅助等对照实验。当前尚未运行这些画质提升步骤。每次只改变少量变量，在相同留出视角、相同相机位置记录图像和指标；不靠增加训练步数解释所有问题。

验收：同一问题区域有前后对照；额外耗时和显存可见；改善失败也保留记录。

### C. 查看与交付

维持原查看器和 SuperSplat 的同模型对照。先记录首帧耗时、稳定帧率和内存，再评估 SOG 压缩和 LOD。转换后的模型另存，并标明压缩或降采样，不能冒充同一模型的纯播放器差异。网页显示坐标与训练坐标区分清楚，模型与相机同时转换。

验收：刷新、切换、定位回房间内部、WASD 和鼠标转头可用。浏览器拒绝鼠标锁定时有拖动转向替代。公开示例只使用获准公开的素材。

### D. 可选的产品化能力

后续考虑任务队列、断点恢复、设备适配、自动质量报告和团队协作。云算力、托管和分享是可选服务，不让本地查看和导出依赖它们。此阶段是规划，不是现有功能清单。

## 成本应该怎样计算

现有硬件下，这次未购买云算力，也未支付按次训练费用；这证明本地验证可以避免新增云 GPU 账单，不证明总成本为零。

总成本包括硬件购置与折旧、电力、存储、采集和清理时间、失败重跑、集成开发、软件许可、维护支持；只有使用云服务时才增加云计算与托管费用。没有功耗实测和当地电价，不填写所谓“每次电费”。

对产品收费的主张：本地资源消耗、软件能力与服务价值应分别说明。希望基础本地路线按真实资源能力运行，不人为增加照片数量的商业门槛；商业化方向可评估便捷工作流、专业交付工具、维护支持和可选服务。尚未承诺永久免费或确定售价。

## 外部路线的边界

AWS 工具箱只验证了全景转换模块：原始方形鱼眼不符合标准 ERP 输入要求；合成 2:1 ERP 能生成六面及遮罩。没有跑通完整训练，不做 AWS 与 Spirula 的画质、速度或费用优劣结论。

MipMap 的版别、图片限制和价格单独记录于 [价格核查](MIPMAP_PRICING_REVIEW.md)。用户在此次使用中遇到的核心流程限制，是 agent 不能在中间调整并积累经验；实施工作因此优先保证阶段可检查、参数可修改、经验可保存。
